# Machine Learning Projects

This folder contains a collection of machine learning notebooks covering classification, regression, NLP, time series, and data analysis tasks.

## Notebook List

- `01.ipynb` - General introductory machine learning notebook.
- `02.Spam.ipynb` - Spam detection using text-based classification.
- `03.Spam_Emails.ipynb` - Spam email classification with email text preprocessing.
- `04.Cartoon.ipynb` - Cartoon or image dataset exploration and modeling.
- `05.OCR_Digits.ipynb` - Optical character recognition for handwritten digit recognition.
- `06.Black_White.ipynb` - Black-and-white image analysis or classification task.
- `07.Credit_Card.ipynb` - Credit card fraud detection or transaction analysis.
- `08.Bitcoin.ipynb` - Bitcoin price trend analysis or prediction.
- `09.Sales.ipynb` - Sales forecasting or sales data analysis.
- `10.Heart_Disease.ipynb` - Heart disease prediction using medical data.
- `11.Cancer_Classification.ipynb` - Cancer diagnosis classification model.
- `12.Air_Quality.ipynb` - Air quality monitoring and prediction analysis.
- `13.Calories.ipynb` - Calorie and nutrition-related data analysis.
- `14.Tip.ipynb` - Tip dataset analysis for regression or customer spending insights.
- `15.News.ipynb` - News text classification or natural language processing task.
- `16.Fuel.ipynb` - Fuel consumption or vehicle efficiency analysis.
- `17.Music.ipynb` - Music genre analysis or recommendation-related modeling.
- `18.Next_Sentence.ipynb` - Next-sentence prediction or NLP sequence modeling.
- `19.Covid.ipynb` - COVID-19 data analysis and trend visualization.
- `20.Stress.ipynb` - Stress detection or health-related prediction task.
- `21.Pfizer.ipynb` - Pfizer vaccine or pharmaceutical dataset analysis.
- `22.Water_Quality.ipynb` - Water quality classification or environmental prediction.
- `23.Billionares.ipynb` - Billionaires dataset analysis and visualization.
- `24.Uber.ipynb` - Uber ride demand or transportation analytics.
- `25.Google_Trends.ipynb` - Search trend analysis using Google Trends data.
